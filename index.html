Backup e compartilhamento

Exportar dados

Gera um arquivo .json com companhias, comerciais, ações e análises SWOT. Envie esse arquivo junto com o index.html para que a equipe veja exatamente os mesmos dados.

Importar dados

Carrega um backup gerado por este sistema. Você escolhe entre somar ao cadastro atual (sem duplicar) ou substituir tudo.

Cadastro comercial

Arquivo separado com clientes, segmentos, graduações, equipes, carteiras e grupos. Use para carregar a base inicial ou levar o cadastro para outro navegador. A importação não sobrescreve dados já preenchidos.

Redefinir dados

Recomeçar do zero um pedaço do sistema: base de clientes, cadastros de apoio, memória comercial ou a base de vendas importada. Você escolhe o que apagar.

Os dados ficam no LocalStorage do navegador, ou seja, são individuais por máquina e por navegador. Limpar o histórico do navegador apaga o cadastro, então faça backups periódicos.
