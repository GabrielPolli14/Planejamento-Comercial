Exportar dados

Gera um arquivo .json com companhias, comerciais, ações e análises SWOT. Envie esse arquivo junto com o index.html para que a equipe veja exatamente os mesmos dados.

Importar dados

Carrega um backup gerado por este sistema. Os dados atuais deste navegador serão substituídos pelo conteúdo do arquivo.

Os dados ficam no LocalStorage do navegador, ou seja, são individuais por máquina e por navegador. Limpar o histórico do navegador apaga o cadastro, então faça backups periódicos.
